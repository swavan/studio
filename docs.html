The s2s command line.

Manage connections, profiles, scripts, notes, and secrets from your terminal.

REFERENCE / v0.2.13124 commands · Verified October 4, 2026

Install the app and CLI

The installer installs Studio and s2s. Manual downloads are available from GitHub Releases.

macOS / Linux

Terminal
curl -fsSL https://studio.swavan.io/install.sh | sh

Windows PowerShell

PowerShell
irm https://studio.swavan.io/install.ps1 | iex

Check the installed version and available commands:

Terminal
s2s --version
s2s --help

Choose a profile

List profiles and use a returned profile ID. Replace example IDs and host names with your own values.

Terminal
s2s profile list
s2s profile default
s2s profile use PROFILE_ID
s2s profile default PROFILE_ID

profile use unlocks a profile and shows its identity. profile default PROFILE_ID changes the default used by CLI commands.

Where a command group supports --profile, put it before the subcommand:

Terminal
s2s ssh --profile PROFILE_ID list
s2s memory --profile PROFILE_ID list

SSH, VNC, RDP, database, snippet, secret, and sync groups also expose --vault-password-env. It takes the name of an environment variable containing the vault password. Connection options such as --password-env refer to the connection password instead.

Common workflows

Add and open an SSH connection

Create a named connection using a private key file, then use the saved connection ID from your list.

Terminal
s2s ssh create --name staging --host staging.example.com --username deploy --private-key-path ~/.ssh/id_ed25519
s2s ssh list
s2s ssh test CONNECTION_ID
s2s ssh connect CONNECTION_ID

Open a saved connection in the desktop app with --gui. Use --shell for the system OpenSSH client, config, and agent instead of the vault credential. Extra OpenSSH arguments require --shell and follow --.

Terminal
s2s ssh connect CONNECTION_ID --gui
s2s ssh connect CONNECTION_ID --shell
s2s ssh connect CONNECTION_ID --shell -- -L 8080:localhost:80

Save scripts and run snippets

Scripts store reusable bodies; snippets provide a command that can run against saved SSH connection IDs.

Terminal
s2s script create --name health-check --content-file ./health-check.sh
s2s script list
s2s snippet create --title uptime --command uptime
s2s snippet list
s2s snippet execute SNIPPET_ID --servers SSH_ID_1,SSH_ID_2

Create and export a note

Terminal
s2s memory create --title "Deployment notes" --content "Verify the service after deploy."
s2s memory list
s2s memory search deployment
s2s memory export-note NOTE_ID --output ./deployment.md --format markdown

Open a saved desktop or database connection

Terminal
s2s vnc list
s2s vnc connect VNC_ID --fullscreen
s2s rdp list
s2s rdp connect RDP_ID
s2s database list
s2s database connect DATABASE_ID

Connect to Docker or save a Kubernetes context

Terminal
s2s docker connect --mode local
s2s kubernetes create --context my-context --kubeconfig-path ~/.kube/config
s2s kubernetes list

Inspect sync configuration

sync show displays endpoint settings without revealing credentials. sync test checks whether the configured bucket can be listed. sync now exchanges the selected profile with its configured sync space.

Terminal
s2s sync show
s2s sync test

Generate shell completions

Write the completion script to a file and load it into the current shell. This example uses zsh.

Terminal
s2s completion zsh > ./s2s-completion.zsh
source ./s2s-completion.zsh

Read the reference

Each entry below contains the installed CLI’s exact help output, including required arguments, defaults, options, and accepted values. Parent entries show options shared by their subcommands. Run help locally if your version differs.

Terminal
s2s ssh --help
s2s ssh create --help
s2s memory folder --help

The help output does not define the full JSON schema for RDP, database, SSH edit, or secret records. Those commands are documented below without invented payloads. Delete and purge commands remove saved data; check their exact options before using them.

Examples illustrate command syntax. Remote connections, writes, secret exports, and sync operations were not executed while preparing this page.
